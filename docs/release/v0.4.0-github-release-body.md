# Kafka GitOps v0.4.0

An independent community-maintained fork of
[joschi/kafka-gitops](https://github.com/joschi/kafka-gitops), originally created
by Shawn Seymour as [devshawn/kafka-gitops](https://github.com/devshawn/kafka-gitops).
Manage Kafka topics, configurations and ACLs from version-controlled desired state.

**Highlights**

- Java 21, Kafka Client 4.4.0, Gradle 9.9.1 and Shadow 9.6.1.
- Verified Kafka 3.2.3 / 3.7.1 / 4.4.0 scenarios with one universal JAR.
- Topic/configuration management and partition increases.
- Deterministic replication-factor increases and explicitly approved decreases.
- ELR-aware safety checks, fresh apply preflight and reassignment completion checks.
- Clearer plan/apply diagnostics, old/new values and sensitive-value redaction.

**Validation:** 1039 Java tests, 26 Python guard tests, 56 CLI smoke checks and
156 codec/JNI checks passed. Separate final-JAR live checks passed: plan/new topic
and RF 1 → 2 on Kafka 3.2.3/3.7.1; plan and RF 1 → 2 → 3 → 2 on Kafka 4.4.0
with ELR enabled.

**Known limitations:** ADS 4.3.1 has not been tested live. Full
SASL/TLS/Kerberos/OAuth and ACL enforcement acceptance, large-scale load and
failure recovery remain incomplete; no vendor or production certification is
claimed. Documented Gradle build-tool advisories are separate from runtime JAR
dependencies. `plan` is read-only; changes require an explicit `apply`.
